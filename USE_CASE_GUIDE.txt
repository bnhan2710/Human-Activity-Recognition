================================================================================
              HƯỚNG DẪN XEM SƠ ĐỒ USE CASE DIAGRAM
================================================================================

File USE_CASE_DIAGRAM.puml đã được tạo với định dạng PlantUML.

================================================================================
                    CÁCH 1: SỬ DỤNG ONLINE EDITOR (NHANH NHẤT)
================================================================================

1. Truy cập: https://www.plantuml.com/plantuml/uml/

2. Mở file USE_CASE_DIAGRAM.puml bằng text editor

3. Copy toàn bộ nội dung file

4. Paste vào PlantUML Online Editor

5. Sơ đồ sẽ tự động hiển thị bên phải

6. Click "PNG" hoặc "SVG" để download hình ảnh

================================================================================
                    CÁCH 2: SỬ DỤNG VS CODE EXTENSION
================================================================================

1. Cài đặt Extension "PlantUML" trong VS Code:
   - Mở Extensions (Ctrl+Shift+X)
   - Tìm "PlantUML" (by jebbs)
   - Click Install

2. Cài đặt Java (nếu chưa có):
   - Download từ: https://www.java.com/download/
   - Install và restart VS Code

3. Cài đặt Graphviz (optional, cho diagram phức tạp):
   - Download từ: https://graphviz.org/download/
   - Install và thêm vào PATH

4. Mở file USE_CASE_DIAGRAM.puml trong VS Code

5. Xem preview:
   - Press Alt+D (hoặc)
   - Right-click → "Preview Current Diagram"

6. Export:
   - Right-click → "Export Current Diagram"
   - Chọn format: PNG, SVG, PDF, etc.

================================================================================
                    CÁCH 3: SỬ DỤNG COMMAND LINE (ADVANCED)
================================================================================

1. Cài đặt PlantUML JAR:
   - Download: http://plantuml.com/download
   - Lưu file plantuml.jar

2. Cài đặt Java JRE/JDK (nếu chưa có)

3. Generate diagram:
   java -jar plantuml.jar USE_CASE_DIAGRAM.puml

4. File PNG sẽ được tạo: USE_CASE_DIAGRAM.png

================================================================================
                    CÁCH 4: ONLINE TOOLS (KHÔNG CẦN INSTALL)

1. PlantText: https://www.planttext.com/

4. ☁️ FIREBASE

   - Đồng bộ real-time

================================================================================
                    TROUBLESHOOTING
================================================================================

❌ ERROR: "Java not found"
   ✅ Cài Java JRE: https://www.java.com/download/
   ✅ Restart VS Code sau khi install

❌ ERROR: "Graphviz error"
   ✅ Cài Graphviz: https://graphviz.org/download/
   ✅ Add to PATH environment variable

❌ ERROR: "Cannot preview"
   ✅ Check PlantUML extension installed
   ✅ Try online editor instead

❌ Diagram không đẹp
   ✅ Adjust layout: left to right, top to bottom
   ✅ Thay đổi spacing: skinparam nodesep 20
